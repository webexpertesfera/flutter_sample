# Flutter Sample

This is a sample Project for Flutter

---

## Versions
- Flutter: 3.24.5
- Dart: 3.5.4

---

## Installation

1. Clone this repository:
   ```bash
   git clone https://github.com/webexpertesfera/flutter_sample.git
   ```

2. Navigate to the project directory:
   ```bash
   cd flutter_sample
   ```

3. Fetch dependencies:
   ```bash
   flutter pub get
   ```

4. Run the app:
   ```bash
   flutter run
   ```

---

## Folder Structure
```
lib/
├── constants/           # Application-wide constants
├── data/                # Preference 
├── localization/        # Language translations
├── logger/              # Logging utilities
├── models/              # Response Model & Data models
├── presentation/        # UI screens, Controllers & Bindings
├── routes/              # Navigation and route management
├── services/            # Backend, Push Notifications and API integrations
├── theme/               # Theme and styling files
├── utils/               # Utility functions and helpers
├── widgets/             # Reusable widgets
└── main.dart            # Application entry point
```
